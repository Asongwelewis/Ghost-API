# Code of conduct

Ghost API follows the [Contributor Covenant, version 3.0](https://www.contributor-covenant.org/version/3/0/code_of_conduct/).
It applies to all project spaces (issues, pull requests, discussions, reviews), and to anyone
representing the project elsewhere.

In short: be respectful, assume good intent, keep criticism about the work and not the person,
and make room for people who are new.

## Reporting

If you experience or witness unacceptable behaviour, report it privately to the project
maintainer, [@Asongwelewis](https://github.com/Asongwelewis), through GitHub. Don't use a
public issue. Reports are handled confidentially, and the maintainer follows the enforcement
guidelines of the Contributor Covenant.
