# Getting help

- **How do I...?** Read the [documentation](docs/getting-started.md) first, then ask in
  [GitHub Discussions](https://github.com/Asongwelewis/Ghost-API/discussions) if it's enabled,
  or open an issue.
- **Ghost flagged correct code:** open a *False positive* issue with the package or framework,
  its version, and a minimal snippet.
- **Ghost missed something, or crashed:** open a *Bug report*.
- **Security:** see [SECURITY.md](SECURITY.md).

This is a volunteer-run project; replies may take a few days.
